## 📖 概要

参加者と結果・景品を入力するだけで、あみだくじを自動生成できる静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

## ✨ 機能

- 参加者（上段ラベル）と結果・景品（下段ラベル）の編集リスト（行の追加・削除、2〜50件、数は自動でそろいます）
- 名簿の一括貼り付け（参加者・結果それぞれに改行区切りテキストを貼って一括反映。空行は無視し、上限50件で切り取ります）
- 「あみだ生成」で Canvas に縦線と横線をランダム生成。横線は同じ段で隣同士が重ならないよう正しく配置されます
- 「スタート」で各参加者の経路を1本ずつ色付きでトレースするアニメーション
- 最終結果（誰がどの結果か）を表で表示
- 結果を Canvas から PNG 画像としてダウンロード
- 結果の印刷（印刷時は入力UIを隠し、参加者→結果の対応表だけを印刷します）
- 参加者・結果リストの自動保存（localStorage `amidaya-data`、再訪時に復元。「リストをリセット」で保存消去＋初期リストに戻ります）
- 設定（参加者・結果）を URL ハッシュにエンコードした共有リンクのコピー／開いたときの自動復元（ハッシュが保存データより優先されます）
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- テーマ切り替え（ダーク／ライト。localStorage `amidaya-theme` に保存）

## 📝 使い方

1. 参加者と結果を入力します（行の追加・削除で人数を調整できます）。
2. 「あみだ生成」を押すとあみだが描かれます。
3. 「スタート」を押すと1人ずつ経路がたどられ、結果表が表示されます。
4. 必要に応じて「結果を画像で保存」で PNG をダウンロードしたり、「共有リンクをコピー」で設定を共有できます。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。あみだ生成アルゴリズム（段数 8+3n、横線の出現確率 0.45、隣同士の重なり防止）と到達先の計算は Web 版と同じで、スタート時のトレースアニメーション（1人あたり最大650ms、合計10秒上限）も再現しています。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Amidaya.exe` を生成
- 参加者・結果は1行1件のテキスト編集（各2〜50件、件数は最後に編集した側に合わせて自動でそろいます）
- Web 版にあって Windows 版にない機能: リストの自動保存、共有リンク、PNG 保存、印刷、テーマ切り替え（代わりに結果をテキストでコピーするボタンを備えます）

## 📋 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- あみだの段数は参加者数に連動します（8 + 3 × 人数）。理由は [DESIGN.md](DESIGN.md) の判断記録（公平性への対応）を参照。
- あみだの横線は段ごとに左から走査し、横線を置いたら次の列をスキップすることで隣接の重なりを防いでいます。
- 経路判定は各段で「右に横線があれば右へ、左にあれば左へ」を順に適用する標準的なあみだのたどり方です。
- 共有リンクは設定 JSON を UTF-8 → Base64URL 化して URL ハッシュに入れています。サーバーには何も送信されません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: amidaya-v1）。
- 純粋ロジック（生成・トレース・解析・共有エンコード）は `app.js` 内で DOM から分離されており、`npm test` で単体テストできます。
